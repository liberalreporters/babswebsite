Quick publishing guide

1. Sign in with the authorised GitHub account. 2. Choose a section from the left menu and select an existing item or create a new one. 3. Add a clear title, correct date, short summary and source. 4. Upload a photograph and write descriptive alt text. 5. Keep the status as Draft until reviewed; set it to Published only after approval, then save/publish. Public pages display published items only.
